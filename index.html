iPhoneで撮影した友人のポーズを、生成AIが漫画のワンシーンに変えるiOSアプリ。Visionで人物を切り抜き、漫画風背景を合成し、ポーズに合った絶妙なセリフをAIが生成。残ったその場で笑い合う体験を、数秒で。

SwiftUI Vision OpenAI API CoreImage
PMの意思決定

開発中盤、チームはAR技術の実装に固執し難航していた。私は判断を下した。「ユーザーが求めるのは高度な技術ではなく、直感的なUXと笑いだ。」ARを捨て、実装リスクの低い2D画像切り抜き＋AI合成へ大胆にピボット。技術より体験を優先したこの決断が、MIXI特別賞獲得に直結した。

FogNot フォグノット

ソロ · デザイン + iOS開発 · 個人開発
個人開発

forget × fog × not — 「課題の霧を晴らす。」

課題やレポートに追われる大学生のための、白・黒・グレーで設計されたミニマルな課題管理アプリ。タイトルと期限を入れるだけ。タスクは近大の授業体系に沿った科目カテゴリ（知能・サイバー・実世界など）で分類でき、共同/個人の区別も1タスクごとに設定可能。Firebase Authentication（メール / Googleサインイン）による共同編集、EventKitによるiOSカレンダー自動同期、WidgetKitによるホーム画面ウィジェット、アプリ内カレンダービューを実装。

SwiftUI Firebase EventKit WidgetKit App Groups Google Sign-In
サクッと追加
タイトルと期限の2項目だけ。発表された瞬間にすぐ追加できる、迷いのないUI。
iOSカレンダー自動連携
EventKitで標準カレンダーに自動書き込み。学業と予定を一つのカレンダーで俯瞰できる。
ホーム画面ウィジェット
WidgetKit + App Groupsで直近5件をホーム画面に常駐。アプリを開かなくても期限が見える。
友達と共有
Firebase Authで友人と共有編集。同じ授業の課題を一緒に管理し、漏れを防ぐ。
